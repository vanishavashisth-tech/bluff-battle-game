BLUFF BATTLE — FIXED STARTER PROJECT

Contents
- index.html: playable browser game
- netlify.toml: static-site publish settings

Run locally
1. Extract this ZIP.
2. Double-click index.html to open it in a modern browser.
3. Add 2–4 player names and start playing.

Deploy to Netlify
1. Log in to Netlify.
2. Choose Add new project / Deploy manually (wording may vary).
3. Drag the extracted folder (the folder containing index.html) into the deployment drop area.
4. Wait for Netlify to finish, then open the generated site URL.

Important limitation
This is a playable pass-and-play prototype on one device. Room codes are labels only; the game does not yet synchronize players across different devices. Do not describe it as real-time online multiplayer until a backend/realtime service is added and tested.
